# 素材库怎么用

## 一条素材的旅程

```
收件箱（乱丢） → 拆零件（提炼） → 资产库（分类存好）
```

## 第一步：往收件箱丢

看到好的文章、视频、金句、自己的灵感，都丢 `素材库/收件箱/`，不分类型、不用整理。

## 第二步：每周拆一次零件

对 AI 说「帮我拆收件箱」，它会把素材拆成三类，存进资产库：

| 拆出什么 | 存到哪 | 例子 |
|---------|--------|------|
| 方法（怎么做的思路/步骤） | `资产库/方法库/` | "他靠评论区挖矿起号，三步…" |
| 模板（照套的格式/结构） | `资产库/模板库/` | "三明治开头：钩子-干货-互动" |
| 案例（具体的故事/数据） | `资产库/案例库/` | "某号 3 个月从 0 到 1 万粉" |

## 第三步：写文章时自动调取

写文章时，AI 会自动从 `资产库/` 找相关的方法、模板、案例来用。你存的越多，它写得越像你。

> 提示：素材库是「原料仓库」，随便丢。`资产库/` 是「弹药库」，只进你认可、确定要用东西。

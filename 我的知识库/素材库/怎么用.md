# 素材库怎么用

## 一条素材的旅程

```
收件箱（乱丢） → 拆零件（提炼） → 资产库（分类存好）
```

## 第一步：往收件箱丢

看到好的文章、视频、金句、自己的灵感，都丢 `素材库/收件箱/`，不分类型、不用整理。

## 第二步：每周拆一次零件

对 AI 说「帮我拆收件箱」，它会把素材拆成四类，存进资产库：

| 拆出什么 | 存到哪 | 例子 |
|---------|--------|------|
| 观点金句（作者的立场/判断） | `资产库/观点库/` | "普通人做内容，最大的对手是自己三天打鱼" |
| 案例（真实例子+数字） | `资产库/案例库/` | "某号 3 个月从 0 到 1 万粉" |
| 结构（怎么排的骨架） | `资产库/结构库/` | "三明治开头：钩子-干货-互动" |
| 标题（靠什么逻辑抓人） | `资产库/标题库/` | "为什么你越努力越穷" |

## 第三步：写文章时自动调取

写文章时，AI 会自动从 `资产库/` 找相关的观点、案例、结构来用。你存的越多，它写得越像你。

> 提示：素材库是「原料仓库」，随便丢。`资产库/` 是「弹药库」，只进你认可、确定要用东西。

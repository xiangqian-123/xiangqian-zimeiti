# 写作总控卡

> 写作全流程的单一事实源。工序顺序 + 每步确认点 + 铁律都在这一张上，照走不漏步骤。
> 触发：写公众号文章时，先读本卡，再进对应 skill（公众号写作 / 标题skill / 去AI味改写）。
> **本卡是写作流程唯一事实源：所有 skill 的流程顺序如与本卡冲突，以本卡为准。**

---

## 流程主线（生成段 + 编辑段，全程 2 个确认点）

### 段一 · 生成（一口气写，中间不打断）

【确认点 1 · 开头定方向】—— 停下等你确认，确认后进入素材、写正文，不再逐项停
- **选题**：查选题候选池，已入选→直接用；无→搜集（选题引擎）
- **定方向**：主题四行（主题 / **核心判断** / 目标读者 / 希望感受）+ 读者画像核对 + 跨篇去重 + 独特角度 + 方向配比闸（瞄最近 5 篇方向标签，某方向连续 3 篇缺席→优先补）
- **核心判断**（判断前置：一句你自己的立场，不是金句、不是抄别人观点）：①先查你自己的判断卡（如已积累），命中 1-3 条列给你认领 ②已跑标题 skill 的，直接取四件套③认知落差当核心判断，不重想 ③都没有→基于选题+已有经历现场提炼一句，你确认 ④都给不出→停，这题没立场，换题。标题的③认知落差、写作的核心判断、结构的反常识论证 = 同一个判断的三张脸，必须咬合
- **工作标题**：起一个能指代这篇的占位标题，不套公式不纠结，结尾再精修

1. **素材包**：观点+金句+案例，当季优先；你自己的复盘原句/改稿样本（如已积累）优先检索；对标素材占 60% 权重
2. **选结构**：先读 `资产库\模板库\结构卡索引.md` 按「结构类型×你的账号」筛规格卡，有就用；没有→拆对标补卡，或课程三件套（钩子开头-干货主体-升华结尾）
3. **写正文**：混合写作模式（人写骨架+AI填肉带标记+人改）；三内核 真/通/流程；账号定位不对就停
→ 一路写到初稿，不回头改

### 段二 · 编辑（写完一次性跑，不设中间确认）

【铁律 · 质检分离】写后检查必须在独立上下文跑（新会话 / 独立 Agent），禁止写完立刻自审

4. **检查链（一次跑完）**：五查（降AI/滑梯钩/情绪曲线/系列引用/语料过门）→ 五关（去AI味/内容力/IP辨识/合规/结构，详见 `标准\降AI规则.md`）→ 15 条反向审计 → 降AI量化核对（<20%，见 `标准\降AI规则.md`）。检查留证据（扫了 N 句/发现 N 处/明细清单）
5. **精修标题**：工作标题 → 定稿标题，套标题公式 + 4U 校验（公式细节见 标题skill）
6. **出检查报告 + 全文**

【确认点 2 · 结尾交稿】—— 正文 + 检查报告 + 精修标题，停下等你确认

- **口述重写（可选降AI步）**：你愿意时录音口述→转文字→只改病句错别字，禁止润色，口述稿直接替代 AI 成稿

### 发布归档

- 你说"定稿"才移：定稿存 `我的账号\公众号\定稿\`；看板更新
- **读者原话回流**：发布时在待办清单记一条"3-7 天后采《标题》读者评论/私信原话"；采到后存 `选题系统\原料区\读者原话\`，写前提炼成选题进候选池

## 铁律层（跨步骤红线）

1. **事实红线**：不编造经历/数字/引用/场景；不借权威之口说金句；不用错别字降智
2. **质检分离**：生产与质检分开上下文，不能又当运动员又当裁判
3. **查重**：篇内（大改必查重：经历/金句/比喻全篇只出现一次）+ 跨篇（写前去重）
4. **同故事一月不超 2 次**
5. **反馈不进正文**：你的纠正/修改思路只给作者听，读者只看修正后的结论
6. **检查留证据**：每查出证据，修改后全量重查
7. **语料优先**：你本人语料 > 任何降AI规则，冲突时保你的语料

---

## 护栏（状态层）

- **自毁模式**：检测到你连续受挫/焦虑/想放弃 → 踩刹车"先停，明天再写"，不催进度、不加码

## 关联工序（非主流程，需要时挂接）

- **拆对标**（对标文章拆解）：加一维——**情绪曲线**（低开还是高开、转折点在哪、峰值靠冲突还是颠覆），不只拆结构/语言
- **标题公式细节**（标题skill）：GGG / 视角翻转 / 四种新角度 / 7 结构 + 钩子自检七要素 + 4U 校验——精修标题时调用

# 爆款标题结构库

> 换词法的结构源。起标题时从这里找「意思一致」的结构，换核心词复用。
> 起步 15 个结构（个人成长 / 女性成长 / 副业赚钱 各 5 个），都是真实爆款标题归出来的。后面你拆对标账号时，自己往里加。

## 怎么用

1. 拆完五件套，用③认知落差一句话当「选结构标尺」
2. 在下面三个赛道里找「表达同样意思」的结构（不是按主题词字面找）
3. 把结构的核心词换成你的主题，**只动 1 个词**，结构、节奏、长度不变
4. 换完检查：意思还一致吗？读者 1 秒代入吗？读起来短吗？都成立 → 用它

## 个人成长赛道

### 1. 翻身改命换人换地换脑（认知重构）
- **它靠什么勾人**：把「改变命运」拆成三个并列的具体动作，排比砸出冲击力。
- **换哪**：三个动作词（换人 / 换地 / 换脑）→ 你的主题对应的三个并列动作。
- **真实例子**：
  - 翻身改命最快的方式：换人，换地，换脑

### 2. 金钱不流向努力，只流向认知（不是A是B）
- **它靠什么勾人**：先否定大众以为的（努力），再给出真答案（认知），制造「我一直想错了」的落差。
- **换哪**：A（努力）和 B（认知）这对对立词。
- **真实例子**：
  - 2026扎心真相：金钱不流向努力，只流向认知
  - 钱是有灵性的：让钱倒追你的5个富人思维

### 3. 屏蔽力是一个人最顶级的能力（最顶级断言）
- **它靠什么勾人**：把一个抽象品质捧到「最顶级」，制造「我没有就输了」的紧迫。
- **换哪**：品质词（屏蔽力 → 钝感力 / 翻篇力 / 独处力）。
- **真实例子**：
  - 屏蔽力是一个人最顶级的能力
  - 一个人最顶级的能力，不是回应一切，是屏蔽一切

### 4. 你不是懒，只是能量太低（给毛病翻案）
- **它靠什么勾人**：给「懒」这种被骂的毛病翻案——不是你的错，是能量低，读者被理解就点。
- **换哪**：被翻案的毛病词（懒）+ 新归因（能量低）。
- **真实例子**：
  - 你不是懒，只是能量太低

### 5. 从讨好到主动筛选（从A到B）
- **它靠什么勾人**：转变句式，给一个可落地的行动路径，读者想知道「怎么做到的」。
- **换哪**：A（讨好）和 B（筛选）这对转变词。
- **真实例子**：
  - 从被动讨好到主动筛选：设立3个边界，让你的社交越走越顺
  - 越讨好别人，越没人把你当回事

## 女性成长赛道

### 1. 女生最大的内耗：太着急（归因断言）
- **它靠什么勾人**：把内耗归因到一个具体毛病，冒号后就是答案，读者想验证「说的对不对」。
- **换哪**：冒号后的归因词（太着急）+ 人群（女生）。
- **真实例子**：
  - 女生最大的内耗：太着急

### 2. 情绪稳定的女人，到底有多赚？（反问算账）
- **它靠什么勾人**：先抛一个状态，再问「有多赚」逼读者算这笔账。
- **换哪**：状态词（情绪稳定）+ 人群（女人）。
- **真实例子**：
  - 情绪稳定的女人，到底有多赚？

### 3. 大龄未婚是优势不是困境（是A不是B）
- **它靠什么勾人**：把大众定义的「困境」翻成「优势」，反常识制造好奇。
- **换哪**：被翻案的状态（大龄未婚）+ 新定义（优势）。
- **真实例子**：
  - 大龄未婚是一种巨大优势，而不是困境

### 4. 去重养自己一遍（重新来过）
- **它靠什么勾人**：给「重新来过」的出口，精准戳有原生创伤 / 委屈的人群。
- **换哪**：人群标签（没被富养过的女生 / 女人四十）。
- **真实例子**：
  - 没被富养过的女生，去重养自己一遍
  - 女人四十，重新养自己一遍

### 5. 焦虑的反义词，是「具体」（反常识反义词）
- **它靠什么勾人**：给抽象情绪一个反常识的「反义词」，用新概念制造好奇缺口。
- **换哪**：情绪词（焦虑）+ 反义词（具体）。
- **真实例子**：
  - 焦虑的反义词，是'具体'

## 副业赚钱赛道

### 1. 我负债113万，公开上岸全过程（第一人称亲历+数字）
- **它靠什么勾人**：第一人称 + 具体负债数字，用真实数字建信任，读者想看「怎么还清的」。
- **换哪**：负债数字（113万）+ 你的真实数字。
- **真实例子**：
  - 我，负债113万，决定公开我的上岸全过程（700粉丝真心话）
  - 从负债累累到全部还清，我的上岸全过程(真实)没有暴富，没有捷径

### 2. 闲鱼7天起号保姆级（平台+天数+背书）
- **它靠什么勾人**：平台名 + 天数 + 「保姆级」，再用「我卖了N单」背书。
- **换哪**：平台（闲鱼）+ 天数（7天）+ 单量（1600单）。
- **真实例子**：
  - 闲鱼7天起号保姆级教程！都是我卖了1600单的经验总结
  - 做了4年闲鱼，终于有人把起号说明白了：不是技巧，是这两个玩法

### 3. 一天收入8500＋短剧推广（收入数字开头）
- **它靠什么勾人**：收入数字开头 + 「新玩法 / 保姆级 / 附教程」，用具体收入勾人。
- **换哪**：收入数字（8500 / 300 / 8W）+ 项目名（小说推文 / 短剧推广）。
- **真实例子**：
  - 一天收入8500＋！做小说推文＋短剧推广，用这个新玩法（附详细教程）
  - 0成本日入300+！短剧推广副业保姆级拆解，新手3步就能上手

### 4. 一人公司的真相（真相揭秘+反常识数据）
- **它靠什么勾人**：「真相」揭秘 + 反常识数据（50%月入不到8000），戳破大众幻想。
- **换哪**：现象词（一人公司）+ 反常识数据。
- **真实例子**：
  - 一人公司的真相：50%月入不到8000
  - 一人公司的残酷真相：99%的人都低估了这5个坑

### 5. 程序员用AI搞副业，我试了6种（人群+工具+亲测）
- **它靠什么勾人**：人群 + 工具 + 「我试了N种」，亲测给结论，读者省了试错成本。
- **换哪**：人群（程序员）+ 工具（AI）+ 数字（6种 / 14万）。
- **真实例子**：
  - 程序员用 AI 搞副业，我试了 6 种方式，告诉你哪些真的能赚到钱
  - 我是如何靠AI编程，3个月搞副业赚到14万

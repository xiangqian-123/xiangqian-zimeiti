# 清单体-数字清单-规格卡

- **文体**：夜读清单体成长文（方法论文，鼓励腔）
- **结构类型**：数字清单式（N 件事）
- **适用场景**：把抽象品质拆成可操作条目的方法论文，适合"做好这 N 件事""X 个习惯"类选题
- **骨架（块清单）**：
  1. 【金句钩子】一句主张 + 一句引用金句
     - 读者此刻：被金句接住
     - 锚点："你有多自律，就有多美好。" / "成长中最大的错误就是一边羡慕别人的生活一边在迷茫中踟蹰不前"
  2. 【引出】点明迷茫时"不妨做好这 N 件事"
     - 读者此刻：期待具体方法
     - 锚点："当你感到迷茫时，不妨静下心来做好这7件事"
  3. 【清单】N 个维度，每个 = 小标题 + 2-3 个要点（时间/空间/形象/健康/预期/情绪/心态）
     - 读者此刻：逐条对照"我做到了没"
     - 锚点："1 时间管理 / 确定先后……巧用空闲……拒绝拖延"
  4. 【收束】回到开头金句 + 晚安语
     - 读者此刻：被安抚、想收藏
     - 锚点："你有多自律，就有多美好" / "亲爱的你，晚安"
- **锚点原句**：见各块
- **来源**：素材库/2.txt《夜读丨自律，做好这7件事》（单篇，待多篇验证）
- **雷区**：条目平均用力无重点；不会有论证冲突/反转；不会质疑读者；温和鼓励腔，结尾必"晚安"式收束

# 观点短文-三段递进-规格卡

- **文体**：夜读观点短文（成长/感悟类，温情升华腔）
- **结构类型**：并列递进三段式
- **适用场景**：讲一个抽象品质（自律/坚持/热爱等）的感悟文，需要情感共鸣 + 轻说教，无案例无数据
- **骨架（块清单）**：
  1. 【钩子】抛"想变好 vs 真变好"的差距，制造共鸣
     - 读者此刻：被戳中"我也这样"
     - 锚点："生活中，每个人都想变得更优秀、更强大。但我们渴望成为的样子和我们真正成为的样子，往往是有差距的。"
  2. 【分论点1·破误区】真正的 X 不靠 A，靠 B
     - 读者此刻：固有认知被轻推开
     - 锚点："真正自律的人，从不觉得'苦'，因为他们不是靠意志力硬撑，而是为了心中的梦想前进。"
  3. 【分论点2·给方法】X 需要目标感（附可操作小动作，如写三个问题）
     - 读者此刻：想"那我该怎么找"
     - 锚点："如果你也有这种困惑，不妨拿出一张纸，写下这三个问题的答案……"
  4. 【分论点3·升华】X 本质是对自己负责
     - 读者此刻：获得意义感、被安抚
     - 锚点："一个人唯有对自己负责时，自律才会被赋予它该有的价值和意义。"
  5. 【收束】点题 + 价值升华（不号召行动，给意义）
     - 读者此刻：温和满足，想点赞
- **锚点原句**：见各块
- **来源**：素材库/1.txt《【夜读】什么是真正的自律？这是我看过最好的答案》（单篇，待多篇验证）
- **雷区**：不会有数据/案例；不会犀利反驳或短句直给；全篇温和升华腔，结尾必落"意义/美好"而非行动指令

# 选题系统

选题的唯一账本在这个文件夹。写没写、写什么，以 `选题候选池.xlsx` 为准。

## 文件清单

| 文件 | 用途 | 谁建 |
|------|------|------|
| 选题候选池.xlsx | 选题库（唯一出口）。写稿从这取题，写完回填状态和定稿标题 | 第一次用时 AI 自动建 |
| 选题词根库.md | 五类词根（情景/情绪/结果/人群/暗号），选题搜集的种子 | 第一次搜集选题时自动建 |
| 标题库.xlsx | 采集的爆款标题（按 URL 去重） | 第一次搜集选题时自动建 |
| 原料区/ | 采集的原材料（有保质期，不直接写稿） | 用到才建子文件夹 |

## 原料区子目录（用到才建）

| 子目录 | 放什么 |
|--------|--------|
| 评论区采矿/ | 对标爆款的高赞评论原话 |
| 读者原话/ | 你自己已发文章的读者评论/私信原话（发布后 3-7 天采） |
| 热榜快照/ | 热榜条目（带日期+角度） |
| 知乎需求/ | 高赞问题 |
| 对标号新动态/ | 对标号的新爆款 |
| 采集记录/ | 词根飞轮的过程文档 |

## 怎么用

1. 搜集选题（说「帮我找选题」）→ 原料进原料区，提炼出的选题追加进候选池
2. 写稿只从候选池取题（按状态筛「已入选」）
3. 写完回填候选池的「定稿标题」列——这是"写没写"的唯一账本

> 候选池的列结构、词根库的格式，都写在「选题引擎」skill 里，AI 会自动按那个建，你不用手动弄。

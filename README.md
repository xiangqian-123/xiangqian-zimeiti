# 向前自媒体 · 写作技能集

《AI 自媒体从 0 到 1》课程的写作技能包，共 7 个 skill。把仓库链接发给 WorkBuddy，它会自动装好；用 WorkBuddy 打开你的知识库即可被 AI 调用。

## 技能清单

| skill | 作用 |
|---|---|
| 公众号写作 | 写公众号正文（选题 → 素材 → 结构 → 初稿 → 检查链） |
| 去AI味改写 | 降 AI 改稿（删对齐痕迹 + 注入真实细节） |
| 选题引擎 | 找选题 / 筛选题 / 起标题 |
| 标题skill | 换词法起标题（复用真实爆款结构换核心词） |
| 长文转短视频文案 | 公众号长文压成 500-1000 字短视频文案 |
| 对标文章拆解 | 拆对标文章，提炼结构卡 / 方法 / 案例 |
| 个人采访 | AI 引导自我采访 → 填个人背景卡 |

## ⚠️ 老学员：替换旧版标题skill

如果你**之前装过旧版**（旧版起标题会固定给 20 个、按「起手式」分类），这次要更新成新版换词法：

1. 在 WorkBuddy 对话框发：`帮我重新安装 https://github.com/xiangqian-123/xiangqian-zimeiti`
2. 说一句验证：`帮我起几个「个人成长」方向的标题`
   - ✅ 新版：AI 先问你这篇的「核心判断 / 反常识点」，每条标题后面标「换自哪条爆款」
   - ❌ 旧版：固定给 20 个、按「一类人 / 数字人群 / 断言…」分类
3. 还是旧的 → 发：`帮我删除标题skill，再重新安装 https://github.com/xiangqian-123/xiangqian-zimeiti`

## 用法

1. 复制仓库链接，在 WorkBuddy 对话框里发给 AI，它会自动装好 7 个 skill
2. 用 WorkBuddy 打开你的知识库，说「帮我找选题」「写一篇…」「去AI味改写」触发对应 skill

## 完整学习包

知识库骨架（背景卡模板、素材库说明、标准、选题系统 README）在课程学习包里，通过课程群 / 网盘发放。装好后跟着「【必读】开始之前.md」走即可。

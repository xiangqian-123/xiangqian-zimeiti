# 向前自媒体 · 写作技能集

《AI 自媒体从 0 到 1》课程的写作技能包，共 6 个 skill。把 `.workbuddy/` 目录放进你的知识库根目录，用 WorkBuddy 打开即可被 AI 调用。

## 技能清单

| skill | 作用 |
|---|---|
| 公众号写作 | 写公众号正文（选题 → 素材 → 结构 → 初稿 → 检查链） |
| 去AI味改写 | 降 AI 改稿（删对齐痕迹 + 注入真实细节） |
| 选题引擎 | 找选题 / 筛选题 / 起标题 |
| 标题skill | 四件套 × 20 起手式 × 三机制 |
| 对标文章拆解 | 拆对标文章，提炼结构卡 / 方法 / 案例 |
| 个人采访 | AI 引导自我采访 → 填个人背景卡 |

## 用法

1. 点「Code」→「Download ZIP」下载，或直接克隆
2. 把 `.workbuddy/` 文件夹放进你的知识库根目录（和「我的个人背景」「素材库」这些并列）
3. 用 WorkBuddy 打开知识库，说「帮我找选题」「写一篇…」「去AI味改写」触发对应 skill

## 完整学习包

知识库骨架（背景卡模板、素材库说明、标准、选题系统 README）在课程学习包里，通过课程群 / 网盘发放。装好后跟着「【必读】开始之前.md」走即可。

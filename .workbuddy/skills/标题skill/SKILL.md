# 标题skill（换词法）

拿一个选题，拆五件套 → 以③认知落差为标尺，去真实爆款标题结构库找「意思一致」的结构 → 换核心词复用 → 每条标来源 → 过三机制事后验证 + 打磨微调。

**换词法 = 唯一产出方法。** 真实爆款标题 → 换一个核心词 → 检查是否成立 → 复用它的结构。不是从抽象判断出发自造句式。

## 为什么是换词法（旧版 20 种起手式已退役）

旧版「20 种起手式」是「先想人性按钮 → 自造句式」，产出又长又假——因为不是复用真实爆款的结构，是从抽象判断出发现编。

换词法反过来：真实爆款标题的结构是经过市场验证的，你只做一件事——**把它的核心词换成你的主题，意思还一致，就用它**。产出短、真、有市场依据。

## 前置执行清单（MUST：开工先复制进对话，逐项打勾，勾完才动笔）

- [ ] 确认账号 → 拆五件套（人群锚/情绪锚/认知落差/内容调性/读者原话锚），每格填具体内容；读者原话锚=去评论区/私信/搜索框挖目标读者原话（不是脑补）
- [ ] 用③认知落差一句话当「选结构标尺」，去标题结构库找「意思一致」的结构（不是按主题词字面找）
- [ ] 每条标题 = 一条真实爆款标题换核心词（数字/主题词/人群），只动 1 个词，结构节奏长度不变
- [ ] 每条标「换自哪条爆款」，能追溯到
- [ ] 每条换完过「检查成立」：意思还一致吗？读者 1 秒代入吗？读起来简短吗？
- [ ] 每条过三机制事后验证 + 打磨微调（可选）
- [ ] 完整输出表格 + 末尾自检勾选

> 清单没勾完 = 不许出标题。每勾一项才算推进，不是读完一遍就往下写。

## 铁律（MUST，违反=任务失败）

1. **换词法 = 唯一产出方法**。每条标题必须来自「一条真实爆款标题换核心词」，能说出「换的是哪条」。禁止凭空自造句子（那是已退役的旧版起手式的老毛病）。
2. **结构源只来自真实爆款**：唯一结构源 = `资产库/标题库/爆款标题结构库.md`（按赛道+结构归类、筛过的）。库里找不到「意思一致」的 → 去你拆对标账号存下来的爆款标题里挖（筛→标结构→补进库→再换词）。**禁止网络搜索**——网络搜出来的都是水的。
3. **③认知落差 = 选结构标尺**。先定「我要表达的意思」一句话，再去找「表达同样意思」的爆款结构。不是先选结构再填词（顺序反了又变成模板腔）。
4. **换词只动 1 个核心词**：数字（3年→5年）、主题词（自律→读书）、人群标签（宝妈→上班族）。保持原结构、原节奏、原长度。禁止加长、加修辞、往「更高级/更文/更术语」换。
5. **事实红线**：换进去的数字、经历、引用必须真实。只准用你自己的真实经历，缺就留白。不编造来源、互动量、收入。
6. **标题党红线**：禁止夸大收入、制造焦虑、恐吓。民族要素禁用。
7. **产出不凑数**：有多少「意思一致」的结构就换多少条（通常 10-15 条），不硬凑、不空行、不重复结构。

## 借口反驳表（MUST：出现下列借口时按强制回应执行，不许自行判断）

| 跳步借口 | 强制回应 |
|---|---|

| "凑不够条数，我多造几条补上" | 铁律 7：换词法不硬凑，有多少换多少；造 = 编造结构，禁止 |
| "这个数字我估一个差不多的" | 铁律 5：数字必须真实，缺就留白 |

## 第 0 步：拆五件套（起标题前先拆）

拿选题问五件事：

| 五件套 | 问什么 | 拆不出会怎样 |
|---|---|---|
| ① 人群锚 | 这选题谁最关心？关心到会点？ | 谁都觉得「跟我无关」 |
| ② 情绪锚 | 这群人憋着什么情绪 / 惯性认知？ | 正确但没人点 |
| ③ 认知落差 | 反常识 / 反惯性的点在哪？（= 本篇核心判断） | 选不到「意思一致」的结构，换出来的平淡 |
| ④ 内容调性 | 干货方法 / 情感共鸣 / 观点立场 / 亲历人设 / 揭秘真相 / 避坑警示（粗略定位） | 找结构时范围跑偏 |
| ⑤ 读者原话锚 | 目标读者自己嘴里怎么描述这个痛点？（去评论区/私信/搜索框挖原话） | 换词换成行业词，读者不认 |

> ③认知落差 = 选结构标尺 + 本篇核心判断。写正文（公众号写作 skill 定方向）时直接取它当立意，不重新想一遍。

**验收（怎样算好）**：五件套每一格都是具体内容——人群锚=身份+场景（不是「职场人」空词），情绪锚=精准情绪（不是「焦虑」），认知落差=反常识点，内容调性=定了位，读者原话锚=挖到原话。有一格空词 = 没过，回去补。

## 第 1 步：换词法（唯一产出方法）

### 1.1 定意思（③认知落差一句话）

把③认知落差压成一句话核心判断。这就是你要「表达的意思」。之后所有换词都围绕这句话展开——**换词换的是主题词，意思（反常识点）不能变**。

例：选题「AI 写作降 AI 味」→ ③认知落差 = 「AI 写的东西像机器，问题不在工具，在你喂进去的词」（不是 A，是 B 结构）。

### 1.2 找结构（拿「意思」去结构库找「意思一致」的爆款）

去 `资产库/标题库/爆款标题结构库.md` 找**表达同样反常识点 / 同样情绪 / 同样人群**的标题。找的是「它表达的意思跟我一致」，**不是「它的主题词跟我字面一样」**。

**怎么判断「意思一致」**：把爆款标题的主谓宾抽出来，看它表达的判断方向，是不是跟我的③认知落差同一个方向。是 → 候选结构；不是 → 跳过。

例：③认知落差 = 「问题不在 A 在 B」。结构库里搜「不是 A，是 B」「真正的 X 从来不是 Y」「你以为的 X，其实是 Y」这类结构的爆款——它们表达的判断方向一致。

**结构库找不到 → 去你拆对标账号存下来的爆款标题里挖**，找到「意思一致」的 → 筛 → 标结构 → 补进 `爆款标题结构库.md` → 再换词。禁止网络搜索。

### 1.3 换词（只动 1 个核心词）

复用候选结构，把核心词换成你的：

- **换数字**：3 年 → 5 年；100 篇 → 50 篇（数字必须真实，用你的真实锚点）
- **换主题词**：自律 → 读书；副业 → AI 写作（同域替换，不跨域）
- **换人群标签**：宝妈 → 上班族；35 岁 → 30 岁

**换词两个合法方向**：往读者原话换、往更具体换。**禁止**往「更高级 / 更文 / 更术语」换。

**保持**：原结构、原节奏、原长度。爆款标题短，换出来的也要短。换完读一遍，比原版长了 = 换多了，收回来。

### 1.4 检查成立

每条换完过三问：
1. **意思还一致吗？** 反常识点跑没跑偏？跑偏 = 换错词，回去换。
2. **读者 1 秒代入吗？** 换成你的主题后，目标读者还认领「这说的是我」吗？
3. **读起来像真实爆款吗？** 简短、顺口、不装。长了/别扭了 = 换坏了。

**验收（怎样算好）**：每条能说出「换自哪条爆款 + 换了哪个词 + 意思没变」。说不出来源 = 这条是编的，删掉。

## 三机制自检（事后验证，不是前置创作）

换词法是「组装 + 换词」，三机制是「验证」——换完之后逐条对着查，不是换之前先想机制（那是旧版起手式的顺序）。

| 机制 | 神经基础 | 问一句 |
|---|---|---|
| ① 自我相关性 | 默认模式网络 | 读者能 1 秒代入一个具体处境吗？（抽象概念/泛人群 = 没过） |
| ② 情绪唤醒 | 杏仁核 | 情绪精准、有态度吗？（「焦虑/内耗」泛词 = 唤醒不足） |
| ③ 好奇缺口 | 多巴胺 | 有反常识/悬念/新信息吗？（正确但平淡 = 无缺口） |

三机制是漏斗：自我相关是第一闸门。三者全亮 = 爆款，缺哪个补哪个。

**好奇缺口三个失败条件**：相关（读者真在意吗）/ 可信（承诺兑现得了吗）/ 交付（正文前 150 字接得住吗）。

**验收（怎样算好）**：没有一条「抽象概念 + 泛人群」开头，自我相关全亮；没有一条触发失败三条件。

## 打磨规律（可选微调，非必做）

换词法换完如果已经够狠，可以不动。要打磨时守这三条：

1. **动作瞬间要「被动、狼狈」，不要「主动、体面」**——「合上书/点收藏」是主动体面，「被问住/一张嘴就哑」是被动狼狈。
2. **后半句落在「狠词」上，不停在「描述」上**——「忘了/看完了」是描述，「哑了/露馅」是狠词。
3. **金句靠「对仗 + 身体意象」**。

> 标杆例子：「学了一肚子，一张嘴就哑了」。

## 输出格式（MUST 用此模板）

```
**选题：**XXX
**核心判断（③认知落差）：**一句话
**读者原话（⑤）：**挖到的目标读者原话 1-3 句

| # | 标题 | 换自（来源爆款标题） | 换的词 |
|---|---|---|---|
| 1 | … | 翻身改命最快的方式：换人，换地，换脑 | 翻身改命→… |
| 2 | … | … | … |

**自检勾选（MUST：写完逐项打勾，勾完才能交）**
- [ ] 每条都来自真实爆款标题换词，能说出「换自哪条」（无凭空自造）
- [ ] 每条只动了 1 个核心词（数字/主题词/人群），结构节奏长度没变
- [ ] 每条换完意思还一致（③认知落差没跑偏）
- [ ] 三机制事后验证过，自我相关全亮；失败三条件过
- [ ] 无编造数字/经历/来源/评级
- [ ] 无网络搜索，结构源来自本地标题库
```

多少条列多少条，不硬凑、不空行、不重复结构。表后不附加「推荐哪几个」——挑，是用户的事。

## 异常处理

| 场景 | 处理 |
|---|---|
| 选题太宽（如「个人成长」「副业」） | 先拆五件套落一个具体人群+角度，再换词；拆不出五件套 = 回去改选题 |
| 结构库找不到「意思一致」的结构 | 去自己拆的爆款标题里挖，补进库再换；都不行 → 反馈「这个意思缺结构源」，不硬编 |
| 换词换完意思跑偏 | 检查成立第 1 问没过，回去换词（换主题词的同域词） |
| 换进去的数字没真实依据 | 留白，或换成你的真实锚点，禁止估一个 |
| 用户说「给几个就行」 | 提醒：换词法有多少结构换多少条，让用户自己挑 |

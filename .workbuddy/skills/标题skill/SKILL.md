# 标题skill（四件套 × 20 种起手式 × 三机制）

拿一个选题，拆四件套 → 按内容调性查结构库骨架 → 20 种起手式各出一个 → 三机制自检 → 完整列出 20 个。

## 前置执行清单（MUST：开工先复制进对话，逐项打勾，勾完才动笔）

- [ ] 确认账号 + 读选题系统（母题地图如有）→ 拆四件套（人群锚/情绪锚/认知落差/内容调性），每格填具体内容
- [ ] 按④内容调性查标题结构库，挑 2-3 个骨架，写出名字
- [ ] 20 种起手式每种出一个，不共用、不跳过、不空行
- [ ] 每个标题过三机制自检，自我相关必须全亮
- [ ] 每个标题按打磨规律改，后半句落狠词不停描述词
- [ ] 完整输出 20 行表格 + 末尾自检勾选

> 清单没勾完 = 不许出标题。每勾一项才算推进，不是读完一遍就往下写。

## 铁律（MUST，违反=任务失败）

1. **每次必须完整输出 20 个标题**，一个起手式一个，缺一不可。用户没要求"只选几种"时，一律 20 个全给。
2. **每种起手式严格套自己的定义**，不两个标题共用一种，不张冠李戴。
3. **先填四件套，再套起手式**——起手式只是"怎么开头"，四件套才是"里面填什么"。四件套没拆出来就套起手式 = 空壳标题。
4. **每个标题过一遍三机制自检**，缺哪个补哪个。
5. **要有"你"的味**：套定义 + 按打磨规律写，不是把起手式当填空模板硬塞。
6. **事实红线**：④第一人称亲历、⑫一句引语、⑬一个造词里的数字和经历必须真实。只准用你自己的真实经历，缺细节就留白。禁止编造具体年份、经历、引语。

## 借口反驳表（MUST：出现下列借口时按强制回应执行，不许自行判断）

| 跳步借口 | 强制回应 |
|---|---|
| "这个选题我熟，直接套断言就行，不用查库" | 必须走第 0.5 步查结构库，写出骨架名，不许跳过 |
| "20 个太多，列几个代表性的" | 铁律 1：固定 20 个，一行不少 |
| "第一人称亲历我编个像样的" | 铁律 6：只准用真实经历，缺就留白 |
| "后半句这样读着顺，不用非得狠词" | 打磨规律 2：后半句落狠词，不停描述词 |
| "三机制脑子里过一遍就行" | 输出末尾必须附自检勾选，逐项打勾 |

## 第 0 步：拆四件套（起标题前先拆，不是直接套起手式）

**先读选题系统（如有母题地图）：** 拆四件套前，先确认账号，读你的 `选题系统\母题地图.md`（如有），找到这个选题落在哪个维度，那个维度的**核心矛盾**就是 ③认知落差 的来源（母题每个维度的核心矛盾天然是反常识点，直接喂给标题钩子）。

拿选题问四件事，拆出才能动笔：

| 四件套 | 问什么 | 拆不出会怎样 |
|---|---|---|
| ① 人群锚 | 这选题谁最关心？关心到会点？ | 谁都觉得"跟我无关" |
| ② 情绪锚 | 这群人憋着什么情绪 / 惯性认知？ | 正确但没人点 |
| ③ 认知落差 | 反常识 / 反惯性的点在哪？ | 平淡没人收藏 |
| ④ 内容调性 | 这条内容是什么味：干货方法 / 情感共鸣 / 观点立场 / 亲历人设 / 揭秘真相 / 避坑警示（粗略定个位） | 骨架选错，论证结构跟正文对不上 |

**判断法则**：四件套拆得出 → 继续走 20 种。拆不出 → **别硬凑，问题在选题不在标题**，回去改选题（加人群、加反差）。

> ③认知落差 = 本篇核心判断。写正文（公众号写作 skill 定方向）时直接取它当立意，不重新想一遍——标题和正文咬合同一个判断。

**验收（怎样算好）**：四件套每一格都是具体内容——人群锚=身份+场景（不是"职场人"这种空词），情绪锚=精准情绪（不是"焦虑"），认知落差=反常识点，内容调性=定了位。有一格是空词 = 没过，回去补。

## 第 0.5 步：按内容调性查结构库骨架（拆完四件套、套起手式之前）

④内容调性定下来后，去你的标题结构库查这个调性下有哪些「逻辑结构类型」可套：

- 库：`选题系统\标题结构库.xlsx`（你自己的标题结构库，自积累；没有就先用下方 20 种起手式里的论证关系）
- 查结构模板的「子方向」列（细分到内容适配粒度）→ 定位到匹配条目 → 看它的「逻辑结构类型」
- 从命中的骨架里挑 2-3 个，作为 20 个标题的**论证结构**来源（不 A 而 B / 越 X 越 Y / 数字清单 / 从 A 到 B / 设问…）

> 起手式管"第一句话从哪切入"，骨架管"整句的论证关系"。两者叠加，标题才有骨有肉；20 个别全是同一种断言。

**验收（怎样算好）**：写出来具体查了哪几个骨架——骨架名 + 套在哪些标题上。查完说不出骨架名 = 等于没查，回去查。

## 20 种起手式总表

起手式 = 标题第一句话从哪切入，决定读者 0.5 秒内被什么勾住。底子：一句话开头能抛的信息就 7 类——人 / 事 / 时 / 地 / 数 / 言 / 态度。20 种是这 7 类的展开。

| # | 起手式 | 从什么切入 | 一句话定义 |
|---|---|---|---|
| ① | 一类人 | 谁 | 用人群标签开头，让读者认领"这说的是我" |
| ② | 状态切片 | 谁 | 用心理/情绪状态开头（睡不着的人 / 高敏感人） |
| ③ | 数字人群 | 谁 | 用年龄/身份数字开头（35岁 / 38岁失业） |
| ④ | 第一人称亲历 | 谁 | 用"我"的真实经历开头，建信任 |
| ⑤ | 概念 | 什么事 | 用抽象概念开头（记忆 / 心力 / 复盘） |
| ⑥ | 一件事 | 什么事 | 用一个具体事件开头 |
| ⑦ | 动作瞬间 | 什么时刻 | 用一个正在发生的具体动作开头 |
| ⑧ | 时间段 | 什么时刻 | 用一个时间区间开头（第3年 / 那半年） |
| ⑨ | 地点/空间 | 什么地 | 用一个空间开头（某城市 / 出租屋 / 地铁上） |
| ⑩ | 时间数字 | 什么数 | 用时间数字建信任（非整） |
| ⑪ | 数量数字 | 什么数 | 用数量数字降成本（极端值） |
| ⑫ | 一句引语 | 什么话 | 用一句被引用的话开头 |
| ⑬ | 一个造词 | 什么话 | 用自造的新词开头 |
| ⑭ | 断言 | 什么态度 | 用下判断的断言开头（就是 / 才是） |
| ⑮ | 祈使否定 | 什么态度 | 用"别 / 不要"开头 |
| ⑯ | 提问 | 什么态度 | 用一个提问开头 |
| ⑰ | 条件 | 什么态度 | 用"如果 / 没有…就"开头 |
| ⑱ | 反差 | 什么态度 | 用一组反差对比开头 |
| ⑲ | 致+共同敌人 | 什么态度 | 用"致XX / 别再被XX骗"喊话开头，树一个共同敌人，让读者跟你站一边 |
| ⑳ | 悬念+省略号 | 什么话 | 话说到一半打住，用省略号留白，勾读者想知道下文 |

## 七类速记

| 类 | 切入 | 起手式 |
|---|---|---|
| 从"谁"切入 | 让人群对号入座 | ①一类人 / ②状态切片 / ③数字人群 / ④第一人称亲历 |
| 从"什么事"切入 | 让读者知道"说什么" | ⑤概念 / ⑥一件事 |
| 从"什么时刻"切入 | 定格一个画面 | ⑦动作瞬间 / ⑧时间段 |
| 从"什么地"切入 | 进入一个空间 | ⑨地点/空间 |
| 从"什么数"切入 | 建信任或降成本 | ⑩时间数字 / ⑪数量数字 |
| 从"什么话"切入 | 抢占解释权 / 留白 | ⑫一句引语 / ⑬一个造词 / ⑳悬念+省略号 |
| 从"什么态度"切入 | 摆明立场 / 喊话树敌 | ⑭断言 / ⑮祈使否定 / ⑯提问 / ⑰条件 / ⑱反差 / ⑲致+共同敌人 |

## 三机制自检（第一性原理，每个标题写完对着查）

三件套（①②③）是"组装版"，三机制是"验证版"——人群锚→自我相关，情绪锚→情绪唤醒，认知落差→好奇缺口，一回事的两面。④内容调性不进三机制，它管的是骨架选择（第 0.5 步）。

| 机制 | 神经基础 | 问一句 |
|---|---|---|
| ① 自我相关性 | 默认模式网络 | 读者能 1 秒代入一个具体处境吗？（还在用抽象概念/泛人群 = 没过闸门） |
| ② 情绪唤醒 | 杏仁核 | 情绪精准、有态度吗？（还在用"焦虑/内耗"泛词 = 唤醒不足） |
| ③ 好奇缺口 | 多巴胺 | 有反常识 / 悬念 / 新信息吗？（正确但平淡 = 无缺口） |

三机制是**漏斗**：自我相关是第一闸门，无关直接划走，情绪和好奇根本没机会触发。三者全亮 = 爆款。缺哪个补哪个。

**验收（怎样算好）**：20 个里没有一个"抽象概念 + 泛人群"开头，自我相关全亮；有任何一个还是泛词、无具体处境 = 没过，回去补。

## 打磨规律（决定标题够不够狠，套定义之外必守）

1. **动作瞬间要"被动、狼狈"，不要"主动、体面"**——"合上书 / 点收藏"是主动体面，"被问住 / 一张嘴就哑"是被动狼狈，后者才戳。
2. **后半句落在"狠词"上，不停在"描述"上**——"忘了 / 看完了 / 眼熟了"是描述，"哑了 / 露馅"是狠词。
3. **金句靠"对仗 + 身体意象"**——"一肚子"对"一张嘴"，进（肚）对出（嘴），才顺口、记得住。

> 标杆例子（⑦动作瞬间）："学了一肚子，一张嘴就哑了"。

**验收（怎样算好）**：20 个标题后半句都落在狠词上（哑了/露馅/认命/算了/咽下去这类），没有一个停在描述词上（忘了/看完了/眼熟了）。扫一遍有描述词收尾 = 没过。

## 异常处理

| 场景 | 处理 |
|------|------|
| 选题太宽（如"个人成长""副业"） | 先拆四件套落一个具体人群+角度，再出 20 个；拆不出四件套就提示回去改选题 |
| 某起手式实在套不进去 | 也出一个，宁可用反常识/场景硬接，不空行、不跳过；④第一人称亲历套不进去时用真实经历硬接，禁编造 |
| 用户说"给几个就行" | 提醒铁律：本 skill 固定出 20 个，让用户自己挑 |

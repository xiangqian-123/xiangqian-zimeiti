# 去AI味改写 Skill

将一段内容、一个选题或一个大纲进行扩充改写，去AI味，产出有人味的文章。

## 核心原理（2026版）

**先删对齐痕迹，再注入真实细节。声纹优先——你本人语料优先于任何通用规则。**

- 降AI的实质是移除AI痕迹（对齐工艺指纹：假坦率、帮腔、均衡罗列、对仗金句），不是添加"人味表演"
- 真正让人文成立的是：真实经历 + 独家判断 + 你本人的说话方式
- 所有痕迹规则以 `标准/降AI规则.md`（中文AI味特征库）为唯一事实源
- **质检分离铁律**：降AI自检必须在写作上下文之外跑（新会话 / 独立 Agent）。让写稿的同一个上下文立刻审自己 = 学生给自己打分——它会记得自己为什么这样写，替刚才的表达找理由。写完立刻自审的降AI，形同虚设。

## 模式一：改写降AI（默认模式）· 工作流

> **执行清单（每次改写第一步：把下面清单原样复制进对话，逐项 `[ ]` 完成打 `[x]`，未打勾不得进下一步）**
> - [ ] 0 加载资产：读声纹（背景卡表达偏好）+ 降AI规则（指定账号再读账号规则）
> - [ ] 1 理解原稿：核心观点清晰（不清晰先帮作者理清，确认再写）
> - [ ] 2 选风格角度 → 输出 1-2 种，停下等作者确认
> - [ ] 3 删对齐痕迹（词汇/句法/结构/编排四层，逐层过声纹优先判断）
> - [ ] 4 结构重建（开头 3 句内 / 波浪式推进 / 收尾有力量）
> - [ ] 5 注入真实细节（至少 2 处只有作者写得出的；事实红线不编）
> - [ ] 6 五层自检 + 跑 `ai_flavor_scan.py` 分数 <20 → 输出全文+审计报告，停下等"满意吗"
> - [ ] 7 回注特征库增量区（发现新痕迹才做）
>
> **铁律：每个"停下确认"是物理动作，不是可选项。作者说"继续"=只前进一步，不是一路写到底。目标锚"过完每个确认点"，不是"交成品"。**

### 第0步：加载资产（必做）

1. 读 `我的个人背景/我的背景卡.md`（声纹——「表达偏好」格里的原话）
2. 读 `标准/降AI规则.md`（语言/结构/内容层规范）
3. 如指定账号 → 读对应的账号规则（如果有）

> **写前不读特征库**。写时只守两条：事实红线（不编造经历/数字/引用）+ 句式从声纹取。`降AI规则.md` 在第六步自检环节读——先流畅写出来，写完再逐层删痕迹。背着禁区清单写，会写出另一种僵硬的AI味。

### 第一步：理解原始内容

- 识别核心观点、可延伸角度、内容类型
- 判断观点是否清晰（不清晰→先帮作者理清，确认后再写）

### 第二步：选择风格角度（需作者确认）

根据内容类型推荐 1-2 种**风格角度**，展示给作者确认后再继续：

| 内容类型 | 推荐风格角度 |
|---------|------------|
| 科技/工具类 | 体验切入 + 产品分享 |
| 思考/评论类 | 碎碎念 + 个人体验 |
| 方法论/教程类 | 概念实操 + 案例展示 |
| 情绪/态度类 | 深度思考 + 概念提炼 |

> ⚠️ 风格角度只决定**结构骨架和叙事视角**。句式、用词、节奏一律从声纹资产（背景卡）取，禁止直套句式模板——公式直套是AI味最大的来源。

### 第三步：删对齐痕迹（对照特征库逐层过）

按特征库顺序扫描原文和草稿：

1. **词汇层**：连接词频次、万能总起/总结、抽象黑话、泛化引用（特征库一）
2. **句法层**：排比、对仗、假坦率开场、自问自答、帮腔结语、万能比喻、量化阈值、**刻意解释句式**（特征库二）
3. **结构层**：总分总八股、碎片化开头段、均衡罗列、空洞结尾（特征库三）
4. **编排层**：过度加粗、emoji、编号嵌套（特征库五）

每个痕迹处理时过一遍**声纹优先判断**：你的语料里出现过类似用法吗？出现过→保留；没出现过且命中特征→删改。

### 第四步：结构重建

1. **开头**：具体行为或场景切入，3句内（30-80字），不铺垫
2. **引出话题**：从小事过渡到大话题（50-100字）
3. **核心观点展开**：波浪式推进（观点→例子→再强调），穿插类比和案例
4. **深层思考**：追问为什么，挖底层逻辑
5. **收尾**：一句有力量的话收住，或重新包装的要求（不喊口号、不空泛升华、不"希望对你有所帮助"）

### 第五步：注入真实细节（声纹驱动）

- 注入作者本人的真实经历/判断（背景卡 + 降AI规则内容层：至少2处"只有作者写得出的内容"）
- 情绪用动作和画面表达，不用情绪形容词
- 加入态度和立场，敢于表达喜恶
- **事实红线**（特征库零·五章）：禁止编造经历/数字/引用/场景来装人味；禁止戏剧化编造（送急诊、凌晨痛哭、突然顿悟）；禁止借权威之口说金句；禁止错别字降智

### 第六步：五层自检 + 审计报告

按特征库逐层过一遍终稿。**终稿必须跑量化扫描（脚本兜底，不靠口头"已自检"）**：`python 工具脚本\ai_flavor_scan.py <稿子路径>`（<20%安全区/20-40%警戒区/≥40%高危区），把分数贴进审计报告。脚本命中项仍需人工过声纹优先判断（脚本不知道哪些是你本人语料用法）。

输出：

```
【降AI审计报告】
- 删除痕迹：X处（词汇X / 句法X / 结构X / 编排X）
- 注入真实细节：X处
- 事实红线核验：✅ 无编造
- 声纹核验：✅ 遮住名字能认出是你吗？能/不能（不能→找一句最不像的重写）
- 残余风险：AI浓度目标<20%（平台爆文安全线）
```

**确认点**：输出全文+审计报告，标注采用的风格角度和核心改动，问作者「满意吗？需要调整风格或细节吗？」

### 第七步：回注特征库（闭环）

本次改稿中发现特征库没有的新AI味痕迹 → 追加到 `降AI规则.md` 增量区，格式：`日期 | 新痕迹 | 发现场景`。

## 模式二：混合写作（从零写新稿，检测盲区打法）

> 作者说"混合模式写一篇XX"或"人写骨架"时启用。适合写新文章：比"AI写全稿再降AI"更省事，且天然抗检（人写骨架+AI填肉+人再改，句级识别仅~63%≈瞎猜；平台低创作度判定看真实经历+信息增量，混合模式天然满足）。

**分工铁律：AI做骨架/过渡/素材，关键段落人写。禁止AI生成可直接发布的段落——AI填的部分必须经作者改过才算完成。**

### 流程

**第1步：作者供原料**（口语级粗糙度即可，不需要成文）
- 这篇想说的核心观点（一两句大白话）
- 真实经历片段（时间/地点/感受，碎碎念也行）
- 态度/立场（喜欢什么、烦什么）
- 已有素材（数据/案例/截图，可选）

**第2步：AI搭骨架，确认后再写**
输出结构提案，并标出三类段落的归属：
- 【原】段落：直接用作者原料，预计哪些
- 【AI填】段落：过渡/解释/展开，预计哪些
- 【缺口】段落：需要作者补真实细节的位置（列出具体缺什么，如"缺一个具体时间""缺当时的数字"）

作者确认骨架或调整后，进入下一步。

**第3步：AI填肉（带标记）**
- 作者原料 → 只微调不改口吻，段尾标【原】
- AI新写 → 段尾标【AI填·需人工改】，写法和模式一完全一致（特征库删痕迹+声纹注入）
- 禁止编造经历/数字补缺口（特征库零·五红线），缺口留给作者

**第4步：作者改【AI填】段落**
按改稿七律重点改：真证据替代社会证据、砍精致表达、一观点一证据、结尾要硬。【AI填】标记没改完不发。

**第5步：AI终检**
改回后跑模式一第六步：扫描脚本量化分 + 五层自检 + 审计报告（报告里注明【原】/【AI填】比例和人工改过段落数）。

### 异常处理
| 场景 | 处理方式 |
|------|---------|
| 作者原料太少（只有一个观点） | 骨架里多标【缺口】，先列问题清单要原料，不硬写 |
| 作者说"你直接全写吧" | 提醒：全AI稿过不了低创作度判定，降权风险在账号层；实在要快就出草稿，但全部标【AI填·需人工改】 |

## 写作原则

### 必须做到
1. **有真实感的开场**：从具体行为、场景、感受开始
2. **有态度有立场**：敢于表达喜恶
3. **有层次的递进**：表面现象 → 底层原因 → 更深思考
4. **有画面感的类比**：来自真实生活经验的比喻
5. **有人味的表达**：像和朋友聊天，不是写报告
6. **有价值的输出**：给观点/给方法/给情绪共鸣
7. **真实为本**：帮作者把自己的想法写好，不编造、不洗稿

## 输出格式

```
# [文章标题]

[正文内容]

---
【降AI审计报告】
- 删除痕迹：X处
- 注入真实细节：X处
- 事实红线核验：✅
- 声纹核验：✅/❌
- 字数：约XXX字
```

## 异常处理

| 场景 | 处理方式 |
|------|---------|
| 作者提供的是选题而非内容 | 先讨论角度和方向，确认后再写 |
| 作者不满意风格选择 | 展示一段改写示例用不同角度，确认方向后重写 |
| 作者要求特定平台（公众号/知乎/小红书/抖音） | 按特征库平台差异速查调整（公众号加粗+空行+01/02分区；小红书短句+钩子；抖音口播念出声测试） |
| 原文观点不清晰 | 先帮作者理清核心观点，确认后再扩写 |
| 原文是纯AI稿，无真实素材可用 | 明确告诉作者哪些位置缺真实经历，请作者补充，禁止编造填补 |

## 注意事项

1. **声纹优先**：背景卡表达偏好 > 特征库规则。冲突时保声纹
2. **保持观点一致**：改写是优化表达不是改变立场
3. **适度即可**：口语化、情绪化要适度，过度会显得刻意
4. **先降AI再打磨**：本skill做底线（不假），语言打磨做上限（好看），顺序不能反
